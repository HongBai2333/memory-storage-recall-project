## 依据和最小基线

原有核心通过 36 项测试，但不存在评测目录、任务账本、公开/Gold 数据契约或冻结实验。方案要求先完成契约与最小闭环；现有核心没有双时间事实、模型、云 Provider 和完整故障控制接口。因此保留单评测控制器和确定性规则的最小基线，不增加 Agent 协作拓扑、通用推理框架或新技能。

业务正确性：同题同预算和身份，只向核心交付允许前缀；证据必须实际承载答案；失败与未执行保留分母；运行完成不等于验收完成。确定性摘录宿主是显式开发基线，不能替代真实固定模型宿主。

能力与拓扑：准入/评分/报告属于治理和确定性计算，回放属于顺序行动，核心属于记忆链，逐题调度属于有界循环。ASSESS：已有业务服务足够做基础真实诊断；ROUTE：单控制器顺序回放；SELECT：保留程序基线，额外命名模式 0 个。没有重复生产证据，Skillization 不适用。
