2026-10-29 新增：独立回测器 `eval-0.1.0` 已形成 P0/P1 基础闭环，并覆盖部分 P2 规则诊断与 P3 加工延迟仿真。回测分期与本页产品分期分别管理；详细范围、命令、数据和未完成项见 [回测实施说明](evaluation.md)。源代码未将回测器反向引入产品服务。

2. 实现独立模型能力接口和 LanceDB provider。绑定模型修订、维度和向量空间，允许本地模型缺失时 blocked_dependency；选定实际模型后跑语义回测。
3. 实现事实候选/确认/CAS、处理任务账本、lease/fence、逐能力依赖闭合水位及容量背压。引入可演进迁移，补足 P0/P1 契约。
4. 在独立 DSH 0.2.2-alpha.2 测试组合中实现工具模式 bridge 和持久事件 Outbox，验证 Native/PTC、卸载重挂、取消与附件边界。再推进上下文接入和 MCP。
